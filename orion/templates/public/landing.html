Questions fréquentes

Est-ce du mutualisé ou du dédié ?

Ni l'un ni l'autre. Vous avez un serveur Linux complet à vous — vos fichiers, votre système, vos droits root — exécuté sur une machine que je gère. C'est la souplesse d'un dédié au prix d'un mutualisé.

Puis-je utiliser mon propre nom de domaine ?

Oui. Un sous-domaine est inclus ; vous pouvez aussi pointer votre domaine ou enregistrer les serveurs que je vous indique. Le certificat HTTPS est géré automatiquement.

Y a-t-il un engagement ?

Non. Le paiement est mensuel et vous pouvez partir quand vous voulez : vous emportez vos données, elles vous appartiennent.

Où sont hébergés les serveurs ?

Sur du matériel que j'exploite moi-même, en France. Pas de sous-traitance à un grand cloud : vous savez où sont vos données.

Le panneau derrière ce service est open source

Ce service tourne sur Orion, un panneau d'hébergement que je développe et maintiens en public. Il décrit la machine qu'il administre, en déduit les offres qu'elle peut porter, et crée les serveurs correspondants. Le code est sous licence MIT : lisez-le, installez-le, critiquez-le.
